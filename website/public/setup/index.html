Setup guide

Install Second Monitor on your PC, connect your tablet, and start using it as a second screen.

Before you start

  • A 64-bit Windows 10 or 11 PC with administrator access.
  • An Android tablet running Android 5.0 or newer and a USB data cable.
  • Internet access on the PC if the installer needs to download dependencies using Windows Package Manager (winget).

Updating from an older version? Right-click the Second Monitor icon in the Windows system tray and select Exit first. The tablet app is unchanged in version 1.5, so you can keep the copy already installed.

Install on Windows

  1. Download the Windows installer, open it, and approve the Windows administrator prompt.
  2. Keep Install missing required programs with winget selected. Setup can install .NET 10 Desktop Runtime, ffmpeg, Android platform-tools (adb), and Virtual Display Driver.
  3. Follow any driver prompts and restart Windows if asked. If Setup lists dependencies it could not install, use the manual installation instructions for those items.

Connect your tablet

  1. On the tablet, open Settings and find Build number under About tablet. Tap it seven times to enable Developer options. Some tablets show Build number under Software information.
  2. Open Developer options and turn on USB debugging. Connect and unlock the tablet using a USB data cable. When it asks Allow USB debugging?, choose Allow.
  3. If the app is new to the tablet, select Install tablet app over USB on the installer’s final page. You can also run Install tablet app (USB) from the Windows Start menu later.

Start streaming

  1. Open Second Monitor from the Windows Start menu or launch the portable app.
  2. Select your secondary virtual display in the monitor list. Choose Connect monitor to activate a disconnected display and begin streaming, or Start if the display is already connected.
  3. Open Second Monitor on the tablet if it hasn’t opened automatically. Drag a window onto the extended desktop. Use Windows Display settings to arrange the two screens.

Stop ends streaming while keeping the extended desktop active. Disconnect monitor removes that display from the active desktop and brings its windows back to the remaining displays.

Manual installation

  1. On Windows, install the .NET 10 Desktop Runtime, a recent ffmpeg build, and Android platform-tools. Put ffmpeg.exe beside the portable app or on your PATH, and add adb to your PATH. GPU capture requires ffmpeg 6.0 or newer.
  2. Install a virtual display driver. To install Virtual Display Driver with winget, open Windows Terminal and run winget install --id=VirtualDrivers.Virtual-Display-Driver -e.
  3. On the Downloads page, get the portable Windows app and the Android APK. Install the APK on the tablet and allow installation from that source if prompted.
  4. Enable USB debugging, connect the tablet, and authorize the PC. Open the portable app and follow the streaming instructions.

Troubleshooting

Click Check setup in Second Monitor to check ffmpeg, the selected encoder, tablet authorization, and the selected monitor. Find the results in the app’s log.

The tablet isn’t detected
Unlock the tablet, try a USB data cable, and check for the USB debugging prompt. If you have adb installed, adb devices should show the tablet as device.
The virtual display doesn’t appear
Confirm the virtual display driver is installed and Windows can see the display. Click Refresh in Second Monitor and select the secondary display.
The tablet screen is black
Switch Screen capture to Standard and try the CPU (libx264) encoder. Check the app log for ffmpeg errors.
Windows are still on the tablet display
Choose Disconnect monitor to return the windows to your remaining displays.
